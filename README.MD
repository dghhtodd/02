《密碼破譯大師》回歸更新：全新玩法與譯碼檔案介面

■ 全新玩法

1. 每日密碼（每日一題，全球同一題目）
   - 以日期作隨機種子，每日午夜更新，所有玩家題目相同
   - 連續破譯日數、當月日曆紀錄，中斷一次重新累積
   - 完成後可一鍵複製戰報，戰報不含答案，方便分享給朋友
   - 每日完成可獲得提示卡 1 張

2. 無盡模式（沒有終點）
   - 三條命，一題機會用完仍未破解才扣一條，難度隨破譯題數自動提升
   - 剩餘機會越多、出手越快，單題分數越高
   - 段位由見習到傳說，記錄最高分與單次最多題數
   - 不再需要無限推出新關卡，難度會跟著你的表現走

3. 成就與提示卡
   - 17 個成就徽章，未解鎖的也會顯示進度
   - 提示卡可在任何模式使用，使用後永久公開一個位置，不會消失
   - 成就與每日完成都會贈送提示卡

■ 介面重製

- 全新譯碼檔案風格：紙張、墨線、印泥紅與藍曬色；判定改用校對符號（墨線、雙線、刪除線）呈現，不再用色塊
- 首頁改成日報頭版式版面：報頭、期號、今日密碼譯碼單、連續紀錄、訓練場名冊與提示卡進度
- 遊戲頁像一張抄碼紙：鍵盤固定在畫面底部，目前輸入行緊貼鍵盤，歷史紀錄向上滾動
- 手機鍵盤依題型自動分欄（5／6／8 欄），40 個數字鍵在 390px 寬也能完整顯示
- 加入蓋印、進度尺與徽章印記，完成與失敗都有明確狀態
- 保留電腦鍵盤快捷操作，補上 focus 外框與減少動態效果支援
- 全站改為繁體中文，統一文案與用語

■ 問題修復

- 修復重玩後按鍵重複觸發、對話框無限疊加的嚴重問題（所有關卡）
- 修復訓練場四「重複數字」有時根本不存在
- 修復通關彈窗「返回主頁」連到不存在頁面的死連結
- 修復干擾計時器在重玩後殘留、越玩越密的問題
- 提示道具改為永久公開指定位置，不再顯示 1.5 秒後消失、也不再覆蓋你已輸入的數字
- 修復數字 0 無法顯示，以及電腦鍵盤無法輸入 9 以上數字的問題
- 修復對話框在部分螢幕未置中、結束後仍顯示空白輸入列的問題
- 複製戰報後加上明確提示，並修正各模式剩餘機會與提示卡數量的顯示
- 移除會直接印出答案的除錯訊息
